Lecture 6: CSS Box Model and Layout

Summary

The CSS box model describes how every HTML element is represented as a box. It includes content, padding, border and margin.

Topics Covered

  • Content
  • Padding
  • Border
  • Margin
  • Width and height
  • Basic page layout

Example Code

.box { width: 300px; padding: 20px; border: 2px solid black; margin: 15px; }

Output

A CSS box contains content, padding, border and margin.
