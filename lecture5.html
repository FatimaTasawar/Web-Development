Lecture 5: CSS Selectors

Summary

CSS selectors are used to select HTML elements that need styling. Different selectors provide different ways to target elements.

Topics Covered

  • Element selector
  • Class selector
  • ID selector
  • Grouping selector
  • Universal selector

Example Code

h1 { color: navy; } .highlight { background: yellow; } #main { padding: 20px; }

Output

Selectors apply different styles to HTML elements.
