Lecture 4: Introduction to CSS

Summary

CSS stands for Cascading Style Sheets. It is used to control the appearance, colors, fonts, spacing and layout of HTML elements.

Topics Covered

  • What is CSS?
  • Inline CSS
  • Internal CSS
  • External CSS

Example Code

Output

CSS changes the appearance of HTML content.
